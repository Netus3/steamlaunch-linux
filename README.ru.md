# SteamLaunch для Linux

[English](README.md) · [Сборка](docs/BUILDING.md) · [Диагностика](docs/TROUBLESHOOTING.md)

Приложение с GUI для запуска стороннего Windows EXE вместо исполняемого файла
установленной игры Steam. Сохраняет цепочку Steam Linux Runtime → Proton и её
окружение. Игра должна быть доступна на твоём Steam-аккаунте.

## Скачать и пользоваться

В **Releases** скачай архив **Linux x86_64 `.tar.gz`**, распакуй **целиком** и
запусти файл **`SteamLaunch`**. Системный Python, pip и FUSE не нужны.
Если файловый менеджер спрашивает — разреши выполнение файла.

Нажми в GUI **«Установить / обновить для текущего пользователя»**, либо выполни
в распакованной папке:

```sh
./install.sh
```

Программа установится без `sudo`, появится в меню приложений. После запуска
установленной версии распакованный архив можно удалить. Для обновления повтори
установку из нового архива: путь запуска останется прежним, профили сохранятся.
Автоматического скачивания или установки обновлений нет.

Можно пользоваться без установки, но тогда **нельзя переносить или удалять
распакованную папку, пока к ней привязаны игры Steam**.

## Совместимость

- Современный Linux x86_64 с glibc. CI-релизы собираются на Ubuntu 22.04
  (glibc 2.35); локальные архивы с суффиксом `-local` могут требовать более новую
  glibc. Старые системы не считаются автоматически поддержанными.
- Обычный Steam, установленный Proton и рабочие видеодрайверы необходимы отдельно.
  Steam из Flatpak, ARM и musl/Alpine пока не поддерживаются.
- GUI поддерживает X11 и нативный Wayland; возможен запасной запуск через XWayland.
  Поддержка Wayland в GUI **не гарантирует** работу Steam Overlay в любом Proton.

## Настройка игры

1. В свойствах игры Steam → **Совместимость** принудительно выбери Proton.
2. Включи Steam Overlay глобально и в свойствах игры.
3. Создай профиль: аккаунт, игра Steam, сторонний `.exe`, рабочая папка и аргументы.
   Сохрани его. По умолчанию рабочая папка — папка EXE; для модов может требоваться
   корень игры. Для аргументов используются POSIX-кавычки; shell-команды не выполняются.
4. Полностью выйди из Steam через **Steam → Выход** и нажми **«Привязать к Steam»**.
   Старая строка сохраняется для отмены, но не выполняется вместе с новой.
5. Открой Steam и запускай через SteamLaunch либо кнопку «Играть» в библиотеке.
6. Для отмены полностью закрой Steam и нажми **«Восстановить»**.

Приложение не завершает Steam само, не меняет `appinfo.vdf` и файлы игр.
Изменяется только LaunchOptions выбранной игры/аккаунта, с резервными копиями,
проверкой конфликтов и журналом восстановления прерванных операций.

### Переход с прототипа 0.1 / исходников

Профили и сохранённые исходные параметры Steam остаются на месте.
Открой **установленную версию** из меню. При закрытом Steam снова нажми
**«Привязать к Steam»**, чтобы обновить путь обёртки. Старая исходная строка не
теряется. Не удаляй старую `.venv`/папку проекта, пока не обновишь или не отменишь
привязки. Ничего не мигрируется в Steam без нажатия кнопки.

### Сохранения и зависимости

Используется **существующий Proton-префикс выбранной игры**. Сторонняя сборка
может изменить его реестр, зависимости и сохранения. Сделай резервные копии
важных данных. Отмена привязки не откатывает файлы префикса.

Достижения, Cloud и мультиплеер не добавляются автоматически. Overlay, учёт часов
и совместимость нужно проверять на конкретной игре. Обход DRM/античита не
реализован. Игры, Proton и игровые DLL в сборку не входят. Компоненты вроде
OpenAL и компиляторов DirectX при необходимости устанавливаются отдельно.

## Диагностика и удаление

```sh
~/.local/bin/steamlaunch doctor
~/.local/bin/steamlaunch gui --display-backend x11
~/.local/bin/steamlaunch gui --display-backend wayland
```

В автоматическом режиме учитывается явно заданная `QT_QPA_PLATFORM`.
Пути по умолчанию:

- профили — `~/.config/steamlaunch`;
- журналы и резервные копии — `~/.local/state/steamlaunch`;
- программа — `~/.local/share/steamlaunch`.

Учитываются XDG_CONFIG_HOME, XDG_STATE_HOME и XDG_DATA_HOME. Не публикуй полные
VDF-копии: в них могут быть личные данные Steam. В логах есть пути и аргументы.

Для удаления **сначала восстанови все привязки**, затем:

```sh
~/.local/bin/steamlaunch uninstall --yes
```

Профили, журналы и резервные копии останутся. При обновлениях старые версии
программы сохраняются, чтобы не удалять библиотеки запущенного процесса.

## Из исходников

Локально пройдены 75 тестов и проверки распакованной сборки на Niri/Wayland и
X11 через XWayland, установки/обновления/удаления и обёртки. Автосборка Ubuntu
с Xvfb и headless Weston подготовлена, но первый запуск GitHub Actions ещё
предстоит после загрузки репозитория. Локальный Arch-архив не является
подтверждённой сборкой для всех дистрибутивов.

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -e '.[dev]'
./run.sh
```
